# SmartRetrofit

Plug-and-play IoT retrofit for existing MSME machines — real-time monitoring, Machine DNA, and predictive maintenance without replacing the shop floor.

**SIH 2026** · Hardware · Smart Automation · Team ID `SIH26219` · Bhimavaram  
**GitHub:** [github.com/swithavanjarana08-commits/smartretrofit](https://github.com/swithavanjarana08-commits/smartretrofit)

## What this repo contains

A product website and live command-centre demo:

- Home, product (interactive 3D SR-32), technology, team, contact
- Simulated MSME cell dashboard (health, sensors, fault injection)
- Black–green industrial UI

## Stack

React 19 · TanStack Start / Router · Tailwind CSS v4 · React Three Fiber · Recharts · Zustand

## Run locally

```bash
npm install
npm run dev
```

Then open the URL printed by Vite.

```bash
npm run typecheck
npm run build
```
